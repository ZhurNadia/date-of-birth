# Birthday Ephemeris — саммарі проєкту

Персональний калькулятор дня народження: вводиш дату — отримуєш купу цікавих обчислень і даних про свій час життя. Working title: **ephemeris**.

## Затверджені блоки функціоналу

### Блок 1 — Час
- Живий лічильник: років / місяців / днів / годин / хвилин / секунд, що тікає щосекунди
- Повних тижнів / місяців / днів прожито
- Скільки годин сну в середньому за рік і всього проспано — користувач обирає тривалість сну (4–10 год/добу, селектор)

### Блок 2 — Календар
- День тижня народження
- Скільки понеділків/вівторків/... прожито **зараз**, і скільки буде **на 25/50/75 років** (таблиця 7 рядків × 4 колонки)
- На який день тижня випаде ДН у майбутньому — таблиця по роках
- День року народження (напр. "45-й день року")
- Юліанська дата (JDN) — з коротким поясненням у інтерфейсі: суцільний рахунок днів від умовної точки відліку, астрономи/хронологи використовують для простого віднімання інтервалів між датами
- Фаза місяця в день народження (рахується астрономічно, без API) + таблиця фаз місяця по роках наперед

### Блок 3 — Ідентичність
- "Круглі" мілстоуни: 10 000 днів життя, 1 000 000 000 секунд, 25 000 годин сну (з урахуванням обраної тривалості сну)
- Покоління (Alpha / Z / Millennial / X / Boomer / Silent) на основі року народження
- Знак зодіаку (західний) + тварина і елемент за східним календарем
- Дата народження римськими цифрами
- **Під питанням**: числа нумерології (число долі, число імені) — поки не вирішено, чи додавати

### Блок 4 — "Світ" (потребує зовнішніх API, ще не реалізовано)
- **Історичні події в цей день** — через **Wikimedia "On this day" API** (безкоштовний, без ключа, CORS дозволяє викликати з фронту напряму). Дані переважно англійською → показувати з кнопкою "перекласти на укр"
- **Кількість людей, народжених у цей день** — оцінка (населення × коефіцієнт народжуваності / 365), НЕ точні дані, з відповідним застереженням. Показувати два числа: приблизно у світі + окремо по країні народження
- **Погода в день народження за містом** — Open-Meteo (історичний архів + геокодинг назви міста, безкоштовно без ключа). Якщо міста немає в списку — пропонувати найближче велике місто в цій країні
- **Курси валют** того дня — Frankfurter.app / exchangerate.host (безкоштовно). Якщо даних за період нема — чесно показувати "даних немає", не вигадувати
- **Золото / нафта** того дня — через **FRED API** (безкоштовна реєстрація ключем, довга історія, державне джерело) як основне; **metals-api.com** як запасний варіант. Ключ ховати за serverless-proxy-функцією, не світити на фронті
- **Ціна біткоїна** того дня — CoinGecko (безкоштовно, дані є тільки з 2010 року — для старших дат чесно показувати "біткоїна ще не існувало")
- **Ціни на хліб/молоко/нерухомість по країнах** — відхилено, бо немає надійного структурованого відкритого джерела. Замість цього: **калькулятор інфляції** — користувач вводить суму, отримує еквівалент купівельної спроможності сьогодні (на основі CPI/індексів інфляції: World Bank / FRED / Eurostat / IMF, залежно від країни)

## Фічі для залучення (затверджено)
- Шерна картинка для соцмереж із ключовими цифрами
- Порівняння двох дат (свій і чужий ДН)
- Живий лічильник просто на сторінці

## Технічні рішення
- **Максимально без бекенду** — 90%+ логіки рахується на фронті (чиста математика з `Date`)
- Бекенд/serverless потрібен лише для блоку "Світ": проксі для API-ключів (FRED, metals-api) і, можливо, кешування запитів
- **Локалізація обов'язкова**: українська + англійська
- Сучасний легкий швидкий фронтенд

## Дизайн-напрямок (затверджений у прототипі)
- Тема: "особистий астрономічний ефемерид/інструмент"
- Палітра: глибокий чорнильно-бірюзовий фон (`#0e161c` / `#0a1117`), латунний акцент (`#c9a24b`), приглушений теал (`#5b9c92`), парчментовий текст (`#e8e2d4`)
- Типографіка: **Fraunces** (серифний, для великих чисел) + **Inter** (body) + **JetBrains Mono** (дані/лейбли, "показання приладу")
- Сигнатурний елемент: кругове "коло-циферблат" із 7 позначками днів тижня, підсвічує день народження
- Односторінковий флоу: hero з інпутом дати → плавний скрол → картки-блоки з'являються послідовно (fade-in-up), точки-навігація збоку для швидкого переходу між блоками 1–4
- Блок 4 ("Світ") має **ліниво підвантажуватись** (lazy load / по кліку), щоб не гальмувати перший рендер і не робити зайвих запитів

## Поточний стан
Готовий **робочий HTML-прототип** (`birthday-ephemeris.html`) з повністю реалізованими блоками 1–3 (Час, Календар, Ідентичність) — усі розрахунки реальні: живий лічильник, підрахунок днів тижня, юліанська дата, фази місяця (астрономічна формула), мілстоуни, покоління, зодіак, римські цифри. Один самодостатній файл, vanilla JS, без залежностей.

## Наступні кроки
1. Перетворити прототип у нормальну структуру проєкту (Vite + vanilla JS/React), приблизно:
   ```
   birthday-ephemeris/
     src/
       main.js
       calendar.js    # блок 2
       time.js        # блок 1
       identity.js    # блок 3
       world.js       # блок 4, API
     index.html
     package.json
     .gitignore
     .env.example     # ключі для FRED, metals-api
   ```
2. Ініціалізувати git, підключити до GitHub-репозиторію
3. Реалізувати блок "Світ": почати з Wikimedia (найлегше) і Open-Meteo, потім курси/золото/нафта/біткоїн, потім калькулятор інфляції
4. Додати перемикач мов UA/EN (закладено в структурі, не реалізовано)
5. Вирішити питання нумерології — додавати чи ні
